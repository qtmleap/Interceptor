# QuickJS local patches

Pinned release: official QuickJS 2026-06-04, archive SHA-256 recorded in quickjs-vendor.json. The CLI, quickjs-libc, std/os and module loader are not compiled. GNU11, `-fwrapv` and `-funsigned-char` match the upstream Clang build settings; assertions remain enabled.

## 0001: bound native work and poll interrupts frequently

The BigInt storage cap is reduced from 1,048,576 to 8,192 bits including sign/storage overhead and intermediate allocations (about 1 KiB of limbs). Operations near that maximum can fail earlier. Small BigInt arithmetic remains available; action JSON still rejects BigInt values. Native BigInt conversion is not preemptible, so limiting only the heap was insufficient: the original decimal-conversion regression took 4.407 seconds in Debug. The interrupt counter is reduced from 10000 to 64 so repeated bounded native operations cannot amortize thousands of calls between budget checks.

Sparse and array-like native loops can iterate billions of absent indices without executing JavaScript bytecode. The array-specific `JS_TryGetPropertyInt64` and `JS_GetPropertyInt64` helpers now poll interrupts and return the existing exception sentinel; TryGet initializes its output to undefined on an early failure. `JS_SetPropertyInt64` and `JS_DeletePropertyInt64` also poll so write/delete tails cannot bypass the budget; the setter consumes its owned value on failure. Array join uses the Int64 getter rather than truncating its index through Uint32. Dense includes/indexOf fast loops also poll directly: many references to a shared large string fit in the heap, yet each comparison can scan that string again. A 100000-element scan comparing distinct million-byte strings required the one-second watchdog before this repair. The default sort comparator also polls, before conversions or comparisons. It uses the existing callback-exception path, retaining the pending interrupt while rqsort finishes with constant-time zero comparisons and the caller frees every retained slot. General object-property helpers are unchanged. Find callbacks already enter `JS_CallInternal`, which polls; length-shrink property scans are bounded by the actual VM heap, rather than sparse logical length.

Before the polling repair, three native sparse/array-like scans required the external watchdog to terminate their owned probe processes after one second. Afterward, the ASan probes returned native timeout statuses near 50 ms. Tests also require recovery on the same surviving executor and cancellation of a sparse scan. A watchdog kill is a failed interrupt test, never successful cancellation.

The setting remains a cooperative 50 ms budget, not process isolation or a hard wall-time guarantee for every native primitive. Final native checks cover evaluation, identifier lookup, invocation and serialization; cleanup is not forcibly interruptible. Physical-device timing remains a release gate.

quickjs-vendor.json pins all vendor bytes, the original and patched whole-file hashes, ten exact substitutions and the generated unified-diff hash. scripts/verify-quickjs-vendor.py reconstructs and hashes the official source, verifies the complete patch and the effective SwiftPM core-only source list and compiler flags. Tampering with bytes, re-pinned limits/unrelated edits, patch drift or required flags is rejected.

For an upstream update, audit the limits, polling paths and ownership again, deliberately update the source/patch record, and rerun Debug/Release, app-linked and sanitizer checks. The verifier fails rather than silently applying the patch to another upstream version. Preserve the MIT notice.
