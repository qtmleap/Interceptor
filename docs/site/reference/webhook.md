# Webhook（将来の機能）

::: warning 未実装
Webhookの配送は実装されていません。現在、プラグインが返すWebhookアクションはアプリ上に表示されるだけで、送信もキュー登録もされません。下記の将来像は保証されず、変わる可能性があります。
:::

## 現在

- `type: "webhook"` のアクションは、形式が検証されて表示されます。アクションの形式は[JavaScript](/reference/javascript.md#返り値)を参照してください。
- ドライランの送信先 `config.endpoints.preview` は合成のダミーで、実在の送信先ではありません。
- 利用者が登録するHTTPS送信先、配送、再試行、アウトボックスはありません。

## 将来の方向

アクションを、利用者が登録した送信先へ送る機能を検討しています。仕様・制限・再試行の方針は未確定です。
