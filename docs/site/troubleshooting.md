# トラブルシューティング

::: info 開発中のプレビュー
ここでは現在のプレビューで起こるエラーだけを扱います。実際の通信での実行や配送はないため、それらに関するエラーはありません。
:::

## パッケージ・マニフェスト

| 症状 | 主な原因 |
| --- | --- |
| マニフェストが無効 | 必須キーの不足、未知のキー、重複キー、`schemaVersion` が1でない、上限超過（[マニフェスト](/reference/manifest.md)） |
| 取り込みで拒否される | パッケージが256 KiBを超える、`source` が128 KiBを超える、キーが `manifest` と `source` 以外 |
| 古いアプリで拒否される | `author` / `summary` は古いクライアントでは未知のキーとして拒否される |
| `request.headers` / `response.headers` で無効 | その場合は `body.mode` を `none` にする |
| `status` で無効 | レスポンスのphase以外では指定できない |

## ドライラン

| 症状 | 原因と対処 |
| --- | --- |
| フックが見つからない（missing hook） | ドライランで選んだ `onRequest` / `onResponse` が、ソースに定義されていない。フックは手動で選ぶ |
| 入力が無効（invalid input） | `event` / `config` がJSONのトップレベルのオブジェクトでない、重複キー、サイズ超過（64 KiB / 8 KiB） |
| 結果が無効（invalid result） | `{actions}` の形でない、アクションが3件以上、`type` が `webhook` でない、`endpointId` がUUIDでない、32 KiB・深さ32を超過、非有限の数値・`BigInt`・関数・thenable・循環参照 |
| 時間切れ（time） | 50 msを超えた。無限ループや重い処理を避けてください |
| メモリ・スタック | ヒープ8 MiB、スタック256 KiBの超過 |
| スクリプトエラー | JavaScriptの実行中に例外が起きた |
| busy | 別のドライランが実行中。待たずに拒否される。終わってから再実行する |

`import`、`fetch`、DOM、ファイル、ネイティブ呼び出し、タイマーは使えません。

## リポジトリ

| 症状 | 原因と対処 |
| --- | --- |
| 署名が無効（signature） | `signature` が壊れている、または署名対象が違う。署名は常に、デコード後のpayloadの正確なバイト列に対して付ける |
| 期限切れ（expired） | `expiresAt` を過ぎている。`--sequence` を増やして再生成する |
| 期限が長すぎる | 発行から90日を超える。CLIは30日で生成する |
| `issuedAt` が先の時刻 | 端末の時刻より5分を超えて未来 |
| `sequence` の拒否 | 前回受け入れた値より小さい（ロールバック）、または同じ値で内容が違う。公開のたびに増やす |
| ハッシュ・サイズの不一致 | `plugins/` を変更したのに `repository.json` を再生成していない。`publish` をやり直す |
| id・name・versionの不一致 | `repository.json` 内のインデックスとパッケージの値が違う |
| 鍵の変更・署名の消失 | 固定済みの鍵のリポジトリは拒否される。鍵のローテーションは未実装 |
