# 権限とデータの共有

::: info 開発中のプレビュー
現在のPluginは、実際の通信にも保存済みの記録にもアクセスしません。ここでは「今できること」と「将来の予定」を分けて書きます。
:::

## 現在の範囲

- ドライランが読むのは合成の入力（[JavaScript](/reference/javascript.md#合成入力の既定値)）だけです。保存済みの記録（Record）の読み取りも、ネットワークへのアクセスもありません。
- 取り込み・保存・編集をしても、コードは実行されません。プラグインが有効になることも、キャプチャ対象のホストが増えることも、Webhookが送信されることもありません。
- マニフェストの `read` や `subscriptions` は取り込み時に検証される宣言です。この宣言はデータへのアクセスを許可するものではありません。
- 表示されるアクションは送信されません。

## 取り込む前に

- プラグインのソース全体を確認してから取り込んでください。
- ドライランの入力や `config` に、**実際のシークレット（トークン、パスワード、Cookieなど）を貼らないでください**。
- リポジトリのインデックスに署名があっても、「安全」という意味ではありません。署名が示すのは、そのインデックスが特定の鍵の持ち主から来たことだけです。プラグインの中身も、公開者の信頼性も保証しません。インデックスと署名については[配布](/guide/distribution.md)を参照してください。
- 公開者テキスト（`author`、`summary`）は、アプリでは未検証のものとして表示されます。

## 将来の予定（未実装）

次のような、キャプチャデータに関する許可はまだ存在しません。実装するときの設計は変わる可能性があります。

- 実際のキャプチャに対するフック実行と、そのための実行許可（グラント）
- 保存済み通信の読み取りと、`read` に基づくデータの絞り込み
- Webhookによる外部送信（[Webhook](/reference/webhook.md)）
- リクエスト送信前・レスポンス返却前の内容変更
- ショートカットからの任意実行

内容変更や手動実行の許可をどのように設定するかは、これから設計する項目です。現在の取り込みや合成テストが、その許可を与えることはありません。

現在、保存済みキャプチャが自動でプラグインへ渡されることはありません。手動で入力したJSONはドライランで実行するスクリプトに渡るため、合成データだけを使ってください。
