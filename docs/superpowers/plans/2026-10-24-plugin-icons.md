# Bundled Plugin Icons and Sources Editing Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for assigned tasks. Keep file ownership separate.

**Goal:** Package PNG/WebP icons with Plugins and reveal Sources + only after Edit.

**Architecture:** Schema 2 may declare `icon: "icon.webp"`. The portable package adds exactly one matching `assets` member encoded as canonical base64. Native reads validated local content asynchronously, reuses a bounded SHA-keyed decode cache and keeps existing tile geometry. Sources owns one EditMode binding.

**Tech Stack:** Swift/Foundation/SwiftUI/UIKit/ImageIO, SwiftData, Python/Bun SDK.

**Spec:** User selected bundled PNG/WebP images and Edit-before-+. Canonical visual rules live in `interceptor-live-scripts-20261018/Interceptor/docs/mock-diff/SPEC.md` (updated before native edits).

## Constraints and decisions

- Optional schema 2 only; v1 unchanged. No icon => no assets field; legacy generated bytes unchanged.
- Icon paths use existing ASCII relative path grammar, <=256 bytes, `.png` or `.webp` lowercase; no source-path collision.
- Exactly one asset matching manifest.icon; base64 decode/re-encode identical. Raw bytes 1...65,536; dimensions 1...1,024 each. Reject animated PNG/WebP and malformed chunk structure. Core validates bounded structure; platform decoder failure safely falls back.
- Preserve 262,144-byte whole-package and 32,768-byte canonical-manifest budgets. Signature/index shape unchanged; icon bytes covered by existing package SHA.
- SDK image file must be regular and every path component must be a real directory (no symlinks/traversal). No remote icon URL, extra asset API, new settings, or image editor.
- Preserve assets across routed source edits. Queue and installed packages use their own validated icon; remote catalog uses accepted cached SHA, never a network request for display.
- Cache decoded thumbnails, max64 image entries / 8MiB decoded cost, plus at most1,600 negative results for the bounded repository catalog; decode and full package reads off MainActor; cache failure safely; key changes reset visible old image.
- Existing clients reject icon packages. Do not publish an icon-bearing production package to existing sources until compatible native release. SDK support and isolated fixtures only in this task.
